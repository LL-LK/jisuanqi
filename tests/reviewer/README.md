## 二、固定用例回归（逐条断言表达式）

### W1 周次（`test_week_enumeration.py`）
| 输入 | 断言 |
|---|---|
| `第7周` | `== {7}` |
| `第7-18周` | `== set(range(7,19))` 且 `len == 12` |
| `第6-7，9-13周` | `== {6,7,9,10,11,12,13}` |
| `第7—12周` | `== set(range(7,13))` |
| `第七周，第八周` | `== {7,8}` |
| `第7、8、9周` | `== {7,8,9}`，且 `len(result)==3`（防「只取最后一个区间」） |
| `6-10周` | `== {6,7,8,9,10}` |

### W2 星期（`test_weekday_enumeration.py`）
| 输入 | 断言 |
|---|---|
| `周一、周三、周四、周五` | `== {周一,周三,周四,周五}`，且 `len==4` |
| `周一 ，周三 ，周四` | `== {周一,周三,周四}` |
| `周一到周五` | `== {周一..周五}`（含中间日） |
| `周一周二周三周四周五` | `== {周一..周五}` |
| `周一、二、四、五` | `== {周一,周二,周四,周五}`，且 `len==4` |

### W3 去重：`agg.exempt_count(学院, 星期, 自习)`
- 同键重复 3 次 → `== 1`；跨周次写法（`第7周`/`第6-7，9-13周`/`第7-18周`）→ `== 1`
- 同一人早/晚 → 早 `== 1` 且 晚 `== 1`
- 同一人周一/周三/周四 → 各 `== 1`
- 5 个不同学号 → `== 5`

### W4 集体申请
- 集体 43 人 + 同班 28 条个人 → `exempt_count == 43`（**不是 71**），`covered_personal == 28`
- 集体只覆盖同日同自习：早自习 7 人照计、其它星期 7 人照计
- `2026-1班` 与 `26-1班` 两种写法互相覆盖
- 同班重复申报取较大人数 + 记「集体免勤重复申报」异常
- 超学院应到（集体 30 > 应到 20）→ 分母 −10 → `rate is None`

### W6 教室分摊
- `allocate` 求和恒等：`sum(allocate(total, weights)) == total`
- `allocate(5,[3,7]) == [2,3]`
- 集成级：教室分摊之和 == 学院总免勤（甲·周一·早 = 5）

### W7 学院出勤率
- 复算差异为 0：`rec.rate == pytest.approx(rec.actual / (rec.expected - rec.exempt), abs=1e-12)`
- 缺率只允许两种原因：`rec.actual is None` 或 `expected - exempt <= 0`
- 实到 = 0 是**有效值**：`actual == 0` 且 `rate == 0.0` 且 `status == '完整'`
- 文字态实到（「免勤」）按缺失处理：`actual is None`、`rate is None`
- 平均出勤率：任一天缺失则整体留空

### W8~W12 输出文件
- 输入明细表 / 免勤表 md5 跑完不变；`export` 拒绝与输入同路径（`ValueError`）
- 输出 `sheetnames == ['雁山（早）','雁山（晚）','屏风']`，长度恒为 3
- 屏风表逐单元格 `==`（含 max_row/max_column）
- 合并区：每个出勤率列的合并行 == 学院行块；缺陷版（漏合并 / 行块不齐）被归一
- 出勤率单元格 `number_format == '0.00%'`；列宽 `>= 10`（防 ###）
- 实到缺失 → 单元格 `is None`（不是 0）

### W13 性质化不变量（hypothesis）
| 编号 | 不变量 | 性质化断言 |
|---|---|---|
| I1 | 脏输入不抛未捕获异常 | `parse_* / normalize_*` 对任意文本均返回定义域内结果；`run()` 缺文件时 `ok is False` 且 `error` 含异常类型名 |
| I2 | 同学号同 (星期, 自习) 最多计 1 次 | `exempt_count == len({sid for 命中该(星期,自习)的记录})` |
| I3 | 分摊和恒等于学院总免勤 | `sum(allocate(t,w)) == t`；不触发封顶时教室分摊和 `== total` |
| I4 | 分母 ≤0 不出率 | `expected - exempt <= 0` ⇒ `rate is None` 且 `status != '完整'` |
| I5 | 实到缺失产出空值而非 0 | `actual is None`、`rate is None` |
| I6 | 输出表名单恒等 | 任意多余表名都被剔除，输出恒为三张表 |

## 四、最易被破坏的三条（需人工样例兜底）

1. **教室分摊和恒等于学院总免勤**——最易被破坏：一旦有人为了「不出超 100%」而在分摊
   环节加封顶/截断，和恒等立刻破，且破得**静默**（数字看着合理）。
   兜底：人工样例必须包含「总免勤 > 某教室应到」的极端块，逐间核对分摊值与学院总数。
2. **同一学号同一 (星期, 自习) 最多计 1 次**——最易被破坏：周次展开、去重、集体覆盖
   三者的先后顺序一旦调换，就会出现「同一人计两次」或「集体与个人重复相加」。
   兜底：人工样例必须放一个「同一学号同时出现在早/晚两表 + 同一人跨两个集体班」的记录。
3. **实到缺失留空 / 分母 ≤0 不出率**——最易被破坏：导出与界面两处都容易用 0 兜底。
   兜底：人工样例必须含「实到为文字『免勤』」「实到为空」「分母恰为 0」「分母为负」四种格子。
