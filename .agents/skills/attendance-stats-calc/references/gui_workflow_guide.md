# 桌面端 GUI 人工复核与操作指引
# Desktop GUI Manual Review & Fallback Workflow Guide

## 1. 定位与人工介入场景 (Purpose & Fallback Scenarios)

“三早一晚免勤自动统计系统”编译为原生 Windows GUI 应用程序（`三早一晚免勤自动统计.exe`，PE Subsystem 2，启动时不分配命令行黑色控制台窗口）。

在常规批处理中，Agent 优先使用 CLI 自动化运行；当自动化流水线检测到严重歧义或管理例外时，Agent 应主动引导用户使用桌面端 GUI 进行人工复核与微调。

### 触发人工复核的核心场景：
1. **同号异名 / 跨学院身份争议（v1.1.0）**：系统已按 `(学号, 星期, 自习)` 去重计 1 人并照常计算，主窗口顶部 Header 下方显示固定争议提示条；需按「免勤核对」页列出的来源表与行号在免勤源表副本中核对更正后重算；
2. **未知专业或新型缩写**：出现未收录于词典的学院简称或班级代码；
3. **机房免勤分摊复核**：单元格填充 `#FFFFF3CD`（浅黄色斜体）的按班级推断或比例分摊免勤人次需要抽查确认；
4. **回填差额与容量超额**：免勤申报总人数超出排课机房总容量（`overflow > 0`），需确认审批单据；
5. **词典规则热重载**：在界面中新增别名或参数后，点击「保存词典」实时生效。

## 2. 界面布局与核心流水线组件 (UI Layout & Pipeline Architecture)

桌面端界面严格遵循 4 卡槽顶部流水线与 4 大功能标签页设计：

### 2.1 顶部常驻四联排核心流水线 (Top 4-Slot Pipeline)
- **`01 明细表` (DropSlot)**：拖入 Excel 明细表（如 `...早晚自习执行情况明细表.xlsx`），自动执行毫秒级前置健康体检并识别周次；
- **`02 免勤表` (DropSlot)**：支持拖入多份免勤 Excel 表格（如 `全免勤大表.xlsx`、`在线存档.xlsx`），自动合并去重并显示统计条数；
- **`开始计算` (ActionSlot)**：点击中央核心操作按钮，执行四阶段异步计算流水线并展示动态进度条；
- **`03 结果工作簿` (ResultSlot)**：计算完成后呈现结果文件路径，支持一键在资源管理器中定位或直接打开 Excel。

### 2.2 四大主功能标签页 (4 Main Tabs)
1. **`概览`**：
   - 展示运行环境规格、数据健康指纹、全校各学院总应到/总实到/总免勤综合看板；
   - 呈现解析统计摘要（有效记录数、因周次/校区过滤条数、占位学号待补人数等）。
2. **`学院免勤统计`**：
   - 逐学院展示各排查日（周一至周日）的早自习免勤、晚自习免勤及免勤合计人次；
   - 支持双击学院行穿透查看当次自习的免勤学生详细名单。
3. **`出勤率`**：
   - 内部包含 **`每日`** 与 **`每周`** 两个子标签页：
     - `每日`：展示各学院每日自习的应到、实到、免勤、出勤率与计算状态；
     - `每周`：展示各学院全周综合出勤率（算术平均值）与已算天数/应统计天数（如 `4/4 天`）。
4. **`词典编辑`**：
   - 表格化呈现「学院别名」、「班级别名」、「校区别名」、「免勤理由分类」与「统计参数」；
   - 底部常驻 **`保存词典`** 按钮，支持前置白名单校验、自动安全备份（`.bak`）与热重载。

### 2.3 辅助工具与对话框
- 界面常驻 **`更多工具…`** 按钮，点击拉起多功能辅助工具箱：
  - **`教室明细`**：逐教室排查每个机房的应到、实到与分摊免勤（`#FFFFF3CD` 浅黄标识）；
  - **`异常清单`**：按 `INFO` / `WARN` / `ERROR` 分级筛选异常提示与审计线索；
  - **`低出勤率复核`**：自动高亮出勤率异常偏低或低于预警阈值的记录，支持双击联动定位到对应教室；
  - **`合成数据自测`**：提供无 PII 隐私风险的纯合成测试数据快速跑通闭环；
  - **`可选设置`**：支持切换「出勤率完整计算模式（严格契约 vs 容错完整）」。

## 3. 标准操作流程 (Step-by-Step Operations)

```
[拖入 01 明细表] ──► [拖入 02 免勤表] ──► [点击 开始计算] ──► [查看 03 结果]
                                                  │
                            ┌─────────────────────┴─────────────────────┐
                            ▼                                           ▼
                   【数据完全规整】                            【发现审计异常】
                 直接查阅出勤率与汇总终稿              进入「更多工具」或「词典编辑」
                 结果自动另存为：                      - 在「异常清单」排查黄标预警
                 1. *_第N周计算结果.xlsx               - 在「词典编辑」新增规范别名
                 2. *_汇总终稿.xlsx                    - 点击「保存词典」后重新计算
```

### 3.1 真实生成工作表与产物
- **明细结果工作簿 (`*_第N周计算结果.xlsx`)**：
  - `雁山（早）`：雁山校区早自习逐教室计算结果与出勤率合并区；
  - `雁山（晚）`：雁山校区晚自习逐教室计算结果与出勤率合并区；
  - `屏风`：屏风校区原始数据，逐单元格 100% 零修改保持；
- **独立汇总终稿工作簿 (`*_汇总终稿.xlsx`)**：
  - 汇总全校各学院整周总和除总和出勤率，恒走严格审计模式，遇争议标记为「待复核」。
