# 本地考勤工具 · 草莓小熊

Windows 桌面工具，用于早晚自习的免勤去重、学院出勤率计算和 Excel 回填。草莓小熊素材随应用内置，打开软件时直接从本机加载。

## 使用方法

1. 从 [Releases](https://github.com/LL-LK/jisuanqi/releases) 下载 Windows x64 便携包并解压，运行 `AttendanceStats.exe`。
2. 选择一份考勤明细或学院汇总表，添加一份或多份免勤表。确认周次后点击「开始计算」。
3. 在「结果工作簿」另存结果，或在「学院免勤统计」导出当前筛选范围。身份冲突可按「免勤核对」页中的来源表和行号回查。

主窗口有「概览」「学院免勤统计」「出勤率」「词典编辑」四个入口。出勤率分为每日和每周，诊断和可选设置收在概览的「更多工具」里。

明细模式按学院回填免勤，生成每日和每周出勤率。默认保留屏风页及人工巡查字段。汇总模式按原表备注中的考勤时段填写早自习、晚自习及合计免勤人次，保留已有出勤率。出勤率的日值采用实到人数除以扣除免勤后的应到人数，周平均按应统计的日值计算，缺一天则留空。

软件先按词典统一学院名称，再按学号、日期和自习时段去重。有效学号不同的同名记录分别保留。同一学号跨学院，或在同一时段对应不同姓名时，相关人次暂缓计入，等待核对。集体申请缺人数时也会标记待核对。

## 隐私使用声明

- **处理范围**。工具读取你选中的考勤表、免勤表和词典。学号、姓名、学院、班级、校区及免勤申请信息用于本次筛选、去重和统计。
- **本地运行**。程序在当前设备处理数据，不上传工作簿，不调用云端模型，也不需要安装本地大模型。草莓小熊图片是制作界面时生成的静态资源，随软件一起分发。
- **本地留存**。人员明细保留在当次运行的内存中。应用会在本机记住周次、输出位置、词典路径和窗口设置。原始输入文件保持原样，结果写入所选位置。
- **导出与分享**。新增统计和核对页包含汇总数字、核对状态和来源行号。手动导出的人员名单含个人信息，诊断日志会做脱敏处理，分享前请核对内容。GitHub 源码和 Release 只提供代码、界面素材、使用说明和默认词典，真实考勤表、免勤表和统计结果均留在本地。

工具右上角可随时查看这份声明。删除结果或名单时，请在本机删除对应文件。

## 离线计算

现有任务由本地规则和 Excel 读写完成。Excel 公式适合计算比例、求和与结构固定的汇总。多工作簿导入、学院别名归一、身份冲突检查和模板回填由本地 Python 程序处理。姓名或归属有冲突时，软件保留来源供人工复核。

## 从源码运行

```bat
python -m pip install -r requirements.txt
python app.py
```

命令行可重复添加免勤表：

```bat
python cli.py --detail 考勤汇总.xlsx --exempt 免勤表A.xlsx 免勤表B.xlsx --week 8 --out 结果.xlsx
```

Windows 单文件构建：

```bat
python -m pytest tests -q
python -m PyInstaller --noconfirm --clean attendance.spec
```

产物位于 `dist/AttendanceStats.exe`。源码测试使用合成数据。
