# 本地考勤工具 v1.1.0 发布说明

- 导出保留明细模板原有的星期和平均列标题。兼容「平均」「周平均」及预留空白表头，出勤率写入标题下方的学院合并区。
- 同号异名/跨学院记录按「学号 × 星期 × 自习」去重计 1 人，不再暂缓计入；主窗口固定位置显示争议提示，出勤率照常计算，来源见「免勤核对」页。
- 身份冲突可按「免勤核对」页的来源表和行号回查。使用说明补充了源表更正、重新计算和终稿待复核的处理步骤。
- 使用说明补充了按教室回填时的估算标记及适用条件。

Windows 单文件程序的文件版本为 `1.1.0.0`。解压发布包后运行 `三早一晚免勤自动统计.exe`，目录中的 `SHA256.txt` 可用于核对随包文件。
